## Öne çıkan projem

### [BağKart Vatandaş Fayda Dashboardu](https://github.com/1emin23/bagkart)

BağKart programının vatandaşlara sağladığı ekonomik faydayı ve yerel ekonomiye katkısını görselleştiren interaktif dashboard.

- React ve Vite tabanlı modern arayüz
- Dönem filtreleri ve etkileşimli grafikler
- Türk lirası ve Türkçe sayı formatları
- PDF rapor çıktısı
- Docker ve Nginx ile production sunumu
